# String Pattern

## Overview
String problems involve character manipulation and pattern matching. Common techniques include:
- Sliding window
- Two pointers
- Pattern matching (KMP, Rabin-Karp)
- Hash-based approaches

## Problems in this category
- 812-rotate-string
- 2487-optimal-partition-of-string

## Learning Path
1. Basic string operations
2. Sliding window for substrings
3. Pattern matching algorithms
4. Advanced string transformations
