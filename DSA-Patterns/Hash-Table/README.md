# Hash Table Pattern

## Overview
Hash Table problems use hash maps/sets for O(1) lookups. Common techniques include:
- Frequency counting
- Two sum variants
- Anagram detection
- Duplicate finding

## Problems in this category
- 1934-evaluate-the-bracket-pairs-of-a-string
- 3420-find-occurrences-of-an-element-in-an-array
- 3709-find-special-substring-of-length-k

## Learning Path
1. Basic hashmap operations
2. Frequency counting and grouping
3. Two pointer + hash table
4. Advanced hash table techniques
