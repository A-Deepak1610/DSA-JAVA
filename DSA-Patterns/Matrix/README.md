# Matrix Pattern

## Overview
Matrix problems work with 2D arrays. Common techniques include:
- Row/column traversal
- Diagonal traversal
- Matrix rotation
- 2D DP

## Problems in this category
- 48-rotate-image
- 1413-maximum-side-length-of-a-square-with-sum-less-than-or-equal-to-threshold
- 1704-special-positions-in-a-binary-matrix
- 1972-rotating-the-box
- 2043-cyclically-rotating-a-grid
- 378-kth-smallest-element-in-a-sorted-matrix

## Learning Path
1. Basic matrix traversals
2. Matrix rotations and transformations
