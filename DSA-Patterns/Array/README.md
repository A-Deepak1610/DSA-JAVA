# Array Pattern

## Overview
Array problems involve working with linear data structures. Common techniques include:
- Two pointers
- Sliding window
- Prefix/Suffix arrays
- In-place modifications

## Problems in this category

### Related LeetCode Problems

- Container with most water
- Best time to buy and sell stock
- Trapping rain water
- And more...
