# Binary Search Pattern

## Overview
Binary Search problems find elements or optimize using logarithmic search. Common techniques include:
- Standard binary search
- Search in rotated arrays
- Binary search on answer
- Finding boundaries

## Problems in this category
- 4-median-of-two-sorted-arrays
- 410-split-array-largest-sum
- 668-kth-smallest-number-in-multiplication-table

- 1675-magnetic-force-between-two-balls
- 1929-maximum-value-at-a-given-index-in-a-bounded-array
- 2027-maximum-number-of-removable-characters

2. Binary search on sorted arrays
