# LinkedList Pattern

## Overview
LinkedList problems involve manipulating node-based linear structures. Common techniques include:
- Slow and fast pointers
- Reversing lists
- Merging lists
- Cycle detection

## Problems in this category
- 2-add-two-numbers
- 61-rotate-list

## Learning Path
1. Basic linkedlist operations (insert, delete, traverse)
2. Reverse linkedlist
3. Cycle detection (Floyd's algorithm)
4. Merge and reorder lists
