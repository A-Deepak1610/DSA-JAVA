# DSA Problems Organized by Patterns

This directory contains all Data Structure and Algorithm problems organized by their core algorithmic patterns.

## Pattern Categories

- **[Array](./Array/)** - Array manipulation, traversal, and search problems
- **[LinkedList](./LinkedList/)** - Linked list operations and transformations
- **[Stack](./Stack/)** - Stack-based problems
- **[String](./String/)** - String manipulation and pattern matching
- **[Bit Manipulation](./Bit-Manipulation/)** - Binary operations and bit-level problems
- **[Math](./Math/)** - Mathematical problems and number theory
- **[Sorting](./Sorting/)** - Sorting algorithms and problems
- **[Binary Search](./Binary-Search/)** - Binary search and searching algorithms
- **[Dynamic Programming](./Dynamic-Programming/)** - DP solutions for optimization problems
- **[Matrix](./Matrix/)** - 2D array/matrix problems
- **[Greedy](./Greedy/)** - Greedy algorithm solutions
- **[Hash Table](./Hash-Table/)** - Hash map/set based solutions

## How to Use

1. Browse the pattern folders to find problems related to specific algorithms
2. Each problem folder contains:
   - `README.md` - Problem description and examples
   - `.java` - Solution implementation
3. Study problems in order of increasing difficulty within each pattern
